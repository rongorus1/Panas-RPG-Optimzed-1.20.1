# Security Policy

## Supported Versions

| Version | Supported |
| ------- | --------- |
| 1.1.x   | ✅        |
| < 1.1   | ❌        |

## Reporting a Vulnerability

Reporta vulnerabilidades en **Security -> Report a vulnerability** o escribe a **rongorus1@users.noreply.github.com**. No abras issue público con exploits.

## Para jugadores sin Premium

**No necesitas comprar Minecraft para jugar Panas RPG.** Solo busca **"Panas RPG"** en la app de **CurseForge** y dale **Install** - se descarga y juega con tu cuenta Microsoft. Si no tienes Premium y quieres usar launcher alternativo, usa nuestro launcher personalizado (ver abajo).

## Launcher No-Premium

Panas RPG es compatible con **RongonLang Launcher v2** (nuestro launcher personalizado). Si no tienes Premium, puedes jugar igual:

**GitHub Launcher:** https://github.com/rongorus1/launcher-minecraft-v2

Descarga RongonLang.Launcher.zip + Rongoland.rar desde Releases, descomprime y dale Play. No necesitas comprar Minecraft ni usar launchers de terceros no seguros.
