# Panas RPG 2.1 — Expediciones, cocina y cooperación

**Versión preliminar para Minecraft 1.20.1, Forge 47.4.10 y Java 17.** El contenido pasó auditoría estructural; falta una instalación limpia y comprobar las cuatro misiones nuevas dentro del juego y en cooperativo.

## Novedades

- 43 JAR incorporados a la instancia frente al paquete 2.0.0: estructuras, arqueología, criaturas, brújulas, aeronaves, cocina interactiva, utilidades cooperativas y compatibilidad EMF.
- Cuatro misiones añadidas en las fases X, XI y XIII. Permanecen 14 capítulos; la revisión estática cuenta 187 misiones y 701 IDs sin duplicados ni dependencias rotas.
- Correcciones puntuales de recetas y datos mediante Paxi. Ajustes locales de Structurify para generación futura, menú y teclas: Better Looting recoge con H.
- El ZIP de CurseForge 2.1 quedó limpio de 52 respaldos/vistas previas de FancyMenu y pasó la auditoría estructural con 0 fallos y 0 avisos. Su publicación en CurseForge se gestiona por separado.

## Instalación manual desde GitHub

El RAR adjunto contiene **287 JAR**, configuraciones, guía, misiones y datapacks. Por los términos de los autores, **JourneyMap, 3D Skin Layers y los resource packs no están dentro del RAR público**. Descárgalos desde sus páginas oficiales siguiendo [INSTALACION-MANUAL-2.1.md](https://github.com/rongorus1/Panas-RPG-Optimzed-1.20.1/blob/main/INSTALACION-MANUAL-2.1.md). Para que los proyectos se descarguen mediante manifest, importa el ZIP de CurseForge en una aplicación compatible cuando esté publicado.
